Quick notes

Wiring

MLX90614 SDA to MCP2221A SDA, SCL to SCL, VCC to sensor supply, GND to GND. I2C needs pull-ups on SDA and SCL to the logic rail. Many breakouts already include them, so add only one pull-up pair on the bus.

Speed

This app configures the MCP2221A for a 100 kHz I2C clock, which is a good fit for the MLX90614 SMBus path.

Security

If direct file open is blocked, serve it from http://127.0.0.1 or http://localhost.
